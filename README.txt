VYSHNAV A P — MULTI-PAGE PORTFOLIO

Files:
- index.html: Home page with portrait and a few featured project samples.
- projects.html: Full project descriptions and navigation to the gallery.
- gallery.html: Project photo archive with multi-image upload and remove controls.
- styles.css: Shared responsive visual theme.
- main.js: Shared navigation and cursor-trail interaction.

To preview:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Use the navigation to move between Home, Projects and Project Gallery.

Project gallery images are stored in browser localStorage on the device/browser where uploaded.
They are not automatically uploaded to a web server. Before deploying publicly, add project photos and upload the complete folder to your hosting provider.

The homepage's project illustrations are authored visual placeholders, not actual photographs of the user's projects.

Home page now includes three AI-generated concept-preview thumbnails (not actual project photographs), animated role text, scroll reveals, interactive project cards, portrait edge fading, and an animated footer signal field.
